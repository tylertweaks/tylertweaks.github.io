Sicherheit der App

Was Tyler auf deinem PC tut, was es nie tut, und warum Windows beim ersten Start eine Warnung zeigt.

Warum warnt Windows beim Installieren?

Windows zeigt bei Programmen ohne gekauftes Herausgeber-Zertifikat eine Warnung — unabhängig davon, was das Programm tut. Tyler ist noch nicht signiert, deshalb erscheint beim ersten Start „Der Computer wurde durch Windows geschützt“ und bei der Installation „Unbekannter Herausgeber“.

  1. Im blauen Fenster auf „Weitere Informationen“ klicken.
  2. Dann auf „Trotzdem ausführen“.
  3. Bei der Frage der Benutzerkontensteuerung mit „Ja“ bestätigen — Tyler braucht Administratorrechte, weil es Windows-Einstellungen ändert.

Lade das Setup nur aus deinem Kundenbereich. Dort steht zu jeder Version die SHA-256-Prüfsumme, mit der du die Datei überprüfen kannst.

Was Tyler tut

  • Ändert nur dokumentierte Windows-Einstellungen, jede einzeln erklärt
  • Sichert vor jeder Änderung den bisherigen Wert
  • Legt vor größeren Durchläufen einen Wiederherstellungspunkt an
  • Fragt beim Start nach Updates und prüft deine Lizenz — sonst nichts im Internet

Was Tyler nie tut

  • Keine persönlichen Dateien lesen oder senden
  • Keine Werbung, keine Tracker, keine versteckten Programme
  • Kein Übertakten, keine Spannungen, nichts an der Hardware
  • Nichts ändern, ohne dass du es angeklickt hast

Alles lässt sich zurücknehmen

  • Einzeln: Jeden Schalter wieder ausschalten — der alte Wert kommt zurück.
  • Im Verlauf: Jede Änderung mit Datum, mit einem Knopf zum Zurücknehmen.
  • Alles auf einmal: „Alles zurücknehmen“ auf der Übersicht.
  • Beim Deinstallieren: Tyler nimmt seine Änderungen zurück, bevor es geht.

Eine Ausnahme: Entfernte Store-Apps installierst du bei Bedarf aus dem Microsoft Store neu. Die App sagt dir das vorher.
