Klassisches Rechtsklickmenü in Windows 11 zurückholen

Windows 11 zeigt beim Rechtsklick ein kurzes Menü. Für den Rest musst du „Weitere Optionen anzeigen“ wählen. Ein Eintrag in der Registry bringt das volle Menü sofort zurück. Ohne Eingriff geht auch Umschalt + Rechtsklick.

Tweak App ansehenJeder Tweak mit Backup und Rückgängig

Auf einen Blick

  • Klassisches Rechtsklickmenü (Windows 11): Mit Vorsicht, In der kostenlosen Version der Tweak App enthalten, Explorer, Kein Neustart nötig, Braucht keine Administratorrechte

Was dieser Tweak macht

Der Eintrag legt einen leeren Schlüssel an, der das neue Menü ausblendet, sodass Windows auf das klassische zurückfällt. Der Explorer muss dafür einmal neu starten.

Ein größeres Windows-Update kann das Verhalten ändern. Dann prüfst du den Eintrag einfach neu. Der Tweak ändert nur deinen Benutzer, nichts am System.

Diese Werte ändert er

So steht es im Katalog der Tweak App, mit dem Wert, auf den zurückgesetzt wird.

  • HKCU\Software\Classes\CLSID\{86ca1aa0-34aa-4e8b-a509-50c905bae2a2}\InprocServer32\(Standard) = ""
    Zurück: gelöscht

Wann es sich lohnt

  • Du klickst oft auf Dinge im erweiterten Menü, zum Beispiel „Kopieren nach“ oder „Öffnen mit“
  • Dir geht der zusätzliche Klick auf die Nerven

Wann besser nicht

  • Dir reicht das kurze Menü
  • Du willst keine Eingriffe in die Registry, die ein Update überholen kann

So machst du es von Hand

Lege vorher einen Wiederherstellungspunkt an, wie in der Anleitung Windows 11 fürs Gaming einstellen beschrieben.

  1. Öffne die Eingabeaufforderung (kein Administrator nötig).
  2. Gib ein: reg add HKCU\Software\Classes\CLSID\{86ca1aa0-34aa-4e8b-a509-50c905bae2a2}\InprocServer32 /f /ve
  3. Starte den Explorer neu: taskkill /f /im explorer.exe und danach start explorer.exe, oder melde dich neu an.

Änderungen an Windows geschehen auf eigene Verantwortung. Die Angaben gelten für Windows 10 und 11, Stand Oktober 2026, und können sich mit Updates ändern.

So nimmst du es zurück

Lösche den Schlüssel wieder mit reg delete HKCU\Software\Classes\CLSID\{86ca1aa0-34aa-4e8b-a509-50c905bae2a2} /f und starte den Explorer neu. In der Tweak App klickst du den Schalter aus.

Als Schalter mit Rückgängig

Die Tweak App von Tyler Tweaks setzt diesen Tweak mit einem Schalter. Sie sichert den alten Wert und lässt dich die Änderung einzeln wieder zurücknehmen. Dieser Tweak ist in der kostenlosen Version enthalten.
