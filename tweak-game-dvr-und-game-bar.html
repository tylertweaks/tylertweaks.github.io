Game DVR und Xbox Game Bar abschalten: Hintergrundaufnahme ausschalten

Die Xbox Game Bar kann beim Spielen im Hintergrund mitschneiden (Game DVR), damit du die letzten Sekunden als Clip speichern kannst. Das kostet etwas Leistung. Wer die Aufnahmefunktion nicht nutzt, schaltet sie aus. Danach kannst du mit der Game Bar keine Clips mehr aufnehmen.

Tweak App ansehenJeder Tweak mit Backup und Rückgängig

Auf einen Blick

  • Game DVR deaktivieren: Mit Vorsicht, Teil der Tweak App mit Lizenz, Overlays, Kein Neustart nötig, Braucht Administratorrechte
  • Rückwirkende Aufnahme der Game Bar aus: Unkritisch, Teil der Tweak App mit Lizenz, Overlays, Kein Neustart nötig, Braucht keine Administratorrechte
  • Game Bar nicht mehr aufpoppen lassen: Unkritisch, Teil der Tweak App mit Lizenz, Overlays, Kein Neustart nötig, Braucht keine Administratorrechte

Was dieser Tweak macht

Es gibt drei getrennte Schalter. Game DVR ist die Aufnahmefunktion selbst. Die rückwirkende Aufnahme hält ständig die letzten Sekunden bereit. Die Game Bar ist die Oberfläche, die beim Spielstart oder über den Xbox-Knopf am Controller aufgehen kann.

Wer mit anderer Software aufnimmt, zum Beispiel mit OBS oder dem Programm der Grafikkartenhersteller, braucht die Aufnahme der Game Bar nicht. Mit Windows + G öffnest du die Game Bar weiterhin, wenn du sie brauchst.

Diese Werte ändert er

So steht es im Katalog der Tweak App, mit dem Wert, auf den zurückgesetzt wird.

Game DVR deaktivieren

  • HKCU\System\GameConfigStore\GameDVR_Enabled = 0
    Zurück: 1
  • HKCU\Software\Microsoft\Windows\CurrentVersion\GameDVR\AppCaptureEnabled = 0
    Zurück: 1
  • HKLM\SOFTWARE\Policies\Microsoft\Windows\GameDVR\AllowGameDVR = 0
    Zurück: gelöscht

Rückwirkende Aufnahme der Game Bar aus

  • HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\GameDVR\HistoricalCaptureEnabled = 0
    Zurück: gelöscht

Game Bar nicht mehr aufpoppen lassen

  • HKCU\Software\Microsoft\GameBar\UseNexusForGameBarEnabled = 0
    Zurück: 1
  • HKCU\Software\Microsoft\GameBar\ShowStartupPanel = 0
    Zurück: 1

Wann es sich lohnt

  • Du nimmst nicht mit der Game Bar auf
  • Du willst im Hintergrund weniger laufen haben
  • Die Game Bar poppt bei dir ungewollt auf

Wann besser nicht

  • Du nutzt Clips und Aufnahmen der Game Bar
  • Du brauchst die Aufnahme über den Xbox-Knopf am Controller

So machst du es von Hand

Lege vorher einen Wiederherstellungspunkt an, wie in der Anleitung Windows 11 fürs Gaming einstellen beschrieben.

  1. Öffne Einstellungen → Spielen → Aufnahmen (je nach Version „Erfassungen“) und schalte das Aufzeichnen im Hintergrund aus.
  2. Öffne Einstellungen → Spielen → Xbox Game Bar und schalte das Öffnen über den Controller aus, wenn du das möchtest.
  3. Per Registry gelten die Werte in der Liste unten. Die ersten beiden Einträge stehen für Game DVR, die nächsten für die rückwirkende Aufnahme, die letzten beiden für das Aufpoppen.

Änderungen an Windows geschehen auf eigene Verantwortung. Die Angaben gelten für Windows 10 und 11, Stand Oktober 2026, und können sich mit Updates ändern.

So nimmst du es zurück

Schalte die Optionen in den Einstellungen wieder ein oder setze die Werte aus der Liste zurück (gelöscht oder 1). In der Tweak App klickst du die drei Schalter wieder aus.
